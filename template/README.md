# Open Jamstack Portfolio Template

This is a ready-to-use static portfolio template with a browser admin.

## Setup

1. Create a repository from this template.
2. Enable GitHub Pages for the `main` branch.
3. Open `/admin`.
4. Enter a fine-grained GitHub PAT with `Contents: Read and write`.
5. Edit your profile and publish.

The admin publishes `public/portfolio-data.json` and staged media in one Git commit through the GitHub REST Git Data API.
